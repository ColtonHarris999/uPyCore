\caption{Container-accelerator resize of a dict or set.
When the object bit is clear, the accelerator hashes every remaining key.
When the bit is set, the core first looks for a type that defines \texttt{\_\_hash\_\_}.
If it finds one, it builds a dict from old slot numbers to hashes, using only \texttt{INT} entries, and the accelerator consumes that dict instead of calling Python.
Slots absent from the dict are hashed by the accelerator.
List growth is a separate doubling copy of the item array and does not use this path.}
\label{fig:resize}
\end{figure*}
